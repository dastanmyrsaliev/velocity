# Velocity

Пет-проект: адаптивный лендинг с использованием HTML5, CSS3, JavaScript (ES6).

## Архитектура

- `img/` - Иконки и картинки.
- `index.html` - Структура HTML-документа.
- `reset.css` - Сброс стилей.
- `script.js` - Логика для табов и плавный скролл.
- `style.css` - Стили для HTML-документа.

## Что используется

- HTML5, CSS3, JavaScript (ES6).
- Семантические теги.
- Методология БЭМ.
- Flexbox.

## Как запустить

```bash
git clone https://github.com/dastanmyrsaliev/velocity.git
```

Запустить с помощью расширения LiveServer или запустить файл index.html в браузере.

## Основные фичи

- Адаптив под мобильные устройства и планшеты от 320px.
- Динамическое переключение табов и плавный скролл.
